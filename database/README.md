# База данных проекта Overwatch Helper

Эта папка содержит все необходимые скрипты для создания, настройки и наполнения базы данных PostgreSQL, используемой в проекте.

## Структура папки

- `create app_overwatch_admin.sql` — скрипт для создания пользователя базы данных и выдачи ему необходимых прав.
- `schema for overwatch.sql` — скрипт для создания таблиц базы данных (структура).
- `seed/` — папка с Python-скриптами для наполнения базы данных данными (роли, герои, контрпики, карты и т.д.).

## Инструкция по развёртыванию БД

База данных создаётся один раз. Вы можете использовать как графический интерфейс (**pgAdmin**), так и командную строку (**psql**).

### Вариант 1: Через pgAdmin
1. Откройте pgAdmin и подключитесь к вашему серверу PostgreSQL.
2. Создайте новую базу данных с именем `overwatch`.
3. Откройте Query Tool для этой базы.
4. Выполните содержимое файла `create app_overwatch_admin.sql` (создание пользователя и прав).
5. Выполните содержимое файла `schema for overwatch.sql` (создание таблиц).

### Вариант 2: Через терминал (psql)
Выполняйте эти команды из любой папки, главное — правильно укажите путь к файлам:

1. Создайте базу данных:
```bash
   createdb -U postgres overwatch
```
2. Создайте пользователя и выдайте права:
```bash
   psql -U postgres -d overwatch -f /путь/до/папки/database/create app_overwatch_admin.sql
```
3. Создайте таблицы:
```bash
   psql -U postgres -d overwatch -f /путь/до/папки/database/schema for overwatch.sql
```

### Наполнение базы данных (сиды)
Когда таблицы созданы, запустите Python-скрипты для наполнения. Запускать их нужно по порядку, находясь в корне проекта (чтобы пути к папке backend корректно находились):
```
python database/seed/01_roles.py
python database/seed/02_heroes.py
python database/seed/03_counter_pick.py
и так далее...
```

## Важно
- Все сид-скрипты подключаются к БД через модуль database.py из папки backend. Убедитесь, что в нём указаны корректные данные (логин, пароль, хост).
